## Learning System

Every topic follows a strict **4-phase pipeline** before moving on:

```
CONCEPT/THEORY ──> BASIC PRACTICE ──> IMPORTANT PROBLEMS ──> COMPANY QUESTIONS ──> REVISION ──> NEXT TOPIC
```

| Phase | What | Where |
|-------|------|-------|
| **01 - Foundation** | Theory, operations, complexity, implementations | `README.md` in each topic |
| **02 - Validation** | Small implementation & edge-case drills | `Basic-Practice/` |
| **03 - Patterns** | NeetCode 150 / Striver / high-frequency problems | `Important-Problems/` |
| **04 - Targeting** | Company-specific interview questions | `Company-Problems/` |

## Problem File Format

Each problem solution follows a consistent schema:

```

Working Solution + Edge Cases
```
